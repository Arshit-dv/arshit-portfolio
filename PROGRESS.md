## 🎯 Mission & Core Objectives

### Primary Objective
Transform Arshit Choudhary’s developer portfolio from a conventional portfolio template into **The Developer’s Chronicle** — an immersive, highly distinctive personal chronicle blending **neo-brutalist print aesthetic, manga chapter pacing, and rigorous engineering journalism**. The portfolio must feel intentionally hand-crafted by a human with an unmistakable visual and editorial identity.

### Core Tenets & Non-Negotiables
1. **Zero Hallucination & 100% Link Integrity:** Every single existing URL, competitive programming profile, and GitHub repository must be preserved with exact fidelity. No fictional metrics, placeholder URLs, or invented technologies.
2. **Defiantly Anti-Generic Design:** Completely discard ubiquitous AI web design tropes (dark glassmorphism, floating neon blobs, generic gradients). Replace them with warm off-white paper, dense black ink, bold vermilion accents, tactile halftone screens, and book typography (*Playfair Display* & *Source Serif 4*).
3. **Substantive Engineering Storytelling:** Present projects as documented chronicles of problem solving — spotlighting architecture choices, statistical algorithms (e.g. PrismR's S3 OOP framework and Box-Cox recommendations), distributed real-time protocols (SportShare WebSockets), and competitive benchmarks.
4. **Editorial Chapter Architecture:** Structure the reader's journey as an episodic volume (Chapters 00 through 05 plus Postscript/Colophon), navigable via an interactive vertical rail.
